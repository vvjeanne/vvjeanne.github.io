Professional Self-Assessment

Self-Assessment

Throughout the computer science program at SNHU, I have developed a better understanding of how different areas of computer science work together to create useful, reliable, and secure applications. The courses I have taken covered a variety of topics, including software development, data structures and algorithms, systems architecture, secure coding, testing, databases, graphics, artificial intelligence, and mobile application development. Working through these subjects has helped me build a broader technical foundation and become more comfortable learning unfamiliar concepts and applying them to different projects. Developing my ePortfolio has also given me a chance to look back at the work I have completed and recognize how much my understanding of computer science has grown.

One of the biggest things I have learned is that there are different ways to approach a problem, and the solution that works best depends on the situation. In CS-300, I worked with data structures and algorithms, which helped me better understand how the way information is organized can affect how efficiently it is accessed and processed. In CS-370, I worked with neural networks and reinforcement learning to develop a pathfinding agent for a treasure hunt game. This gave me experience with a different kind of problem-solving, where the agent learns to make decisions based on rewards and repeated training. I also gained experience with graphics in CS-330, including creating a simple Arkanoid game. These courses helped me explore different areas of computer science and showed me that the skills used in one area can often be applied to another.

My coursework has also helped me understand the importance of software engineering, database design, and security. In CS-320, I worked with software testing and learned more about how tests can help identify problems and verify that an application behaves as expected. CS-340 introduced me to working with databases and using stored information in an application. In CS-305, I worked on the Artemis Financial project, which focused on vulnerability assessments and secure coding. This gave me a better understanding of how to identify potential security risks and apply secure coding practices to help protect an application and its information. Other courses, including CS-230 and CS-255, helped me develop a better understanding of systems architecture, software design, and the process of translating user needs into technical requirements. These experiences have shown me that writing code is only one part of software development. Applications also need to be organized in a way that makes them easier to maintain, tested to catch problems, and designed with security and the needs of their users in mind.

Communication and collaboration have also been part of my experience throughout the program. Although much of my project work has involved developing solutions independently, discussion assignments have given me opportunities to exchange ideas with classmates, respond to their approaches, and consider perspectives different from my own. Some assignments also required collaboration with peers on group posts, which involved contributing to a shared response and working toward a common result. These experiences helped me recognize that communicating technical ideas is an important part of computer science, even when people approach a problem differently. In a professional setting, I would need to communicate with teammates and stakeholders, understand their requirements, explain technical decisions, and be open to feedback. I would like to continue improving these skills as I gain more experience working on software projects.

As I progressed through the program, I also discovered that I enjoy mobile application development more than I originally expected. CS-360 gave me the opportunity to build an Android application, and I enjoyed being able to see the results of my work through an actual user interface and working features. This experience helped shape my professional interests, and I have developed a new interest in creating mobile apps. I also have some interest in game development, especially after working with graphics and creating a simple Arkanoid game in CS-330, although I have less experience in that area so far. I would be interested in exploring it further in the future. For now, mobile application development is an area I would particularly like to continue learning about and potentially pursue professionally.

Completing the program has helped me become more confident in my ability to learn new technologies, troubleshoot any problems, as well as improve an existing solution when something does not work as expected. It has also taught me that development involves more than getting a program to run. Understanding the user’s needs, choosing appropriate data structures, organizing databases, testing functionality, and protecting information all contribute to a successful application. I know there will still be new tools and concepts to learn as I enter the computer science field, but I feel that my coursework has given me a solid foundation to build on. I want to continue developing my programming skills, gain more practical experience, and explore opportunities that allow me to create applications that are useful and enjoyable for people to use.

The technical artifacts included in this portfolio demonstrate different areas of my development as a computer science student. I chose to build on the K-Pop Concert Tracker application I originally developed in CS-360 because it gave me the opportunity to revisit an existing project I enjoyed creating, and apply what I had learned in later courses. The application provides a way for users to manage upcoming K-pop concerts, including adding, editing, deleting, and organizing event information. For my capstone, I focused on improving three areas of the application: software engineering and design, data structures and algorithms, and databases.

The software engineering and design artifact focuses on improving the application’s architecture, separating responsibilities, strengthening password security, and protecting access to user data. These changes helped make the application more organized and maintainable while reinforcing the importance of considering security throughout development. The data structures and algorithms artifact focuses on organizing and retrieving concert information, prioritizing upcoming events, improving category lookups, and detecting scheduling conflicts. These improvements demonstrate how choosing appropriate data structures and algorithms can make an application more useful and improve how it processes information. The database artifact focuses on improving how information is stored and managed through Room, database entities, data access objects, repositories, and migration support. It also addresses the importance of reliable database operations and keeping data management separate from the user interface.

Although each artifact focuses on a different area, they are connected through the same application and its overall purpose. The database provides the information the application depends on, the data structures and algorithms help organize and process that information, and the software engineering improvements help keep the application secure, maintainable, and easier to extend. Working on these enhancements helped me understand how decisions in one area can affect the rest of an application. For example, changes to database access can affect how the user interface loads information, while improvements to data organization can support features that help users find and manage their concerts more easily.

Each of these artifacts demonstrate my ability to evaluate an existing application, identify areas for improvement, and apply concepts from different parts of the computer science program to make meaningful changes. They also show how my understanding has developed beyond simply writing code to considering the structure, security, efficiency, and long-term maintenance of a complete application.
